csl-pyutil is a package of **generic, non-Sanskrit-specific Python helpers** (`review_sheet`,
`evidence`, `anatomy`, `integrity_tripwire`, …) — distinct from
[`sanskrit-util`](https://github.com/sanskrit-lexicon/sanskrit-util), which is scoped to
Sanskrit string and transcoding work.
